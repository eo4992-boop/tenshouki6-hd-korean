# 신장의 야망 6 천상기 HD 한국어 패치

> NOBUNAGA'S AMBITION: Tenshouki with Power Up Kit HD Version

정식으로 보유한 Steam 게임의 로컬 파일을 대상으로 한국어 패치를 연구·제작하는 프로젝트입니다.

## 목표

- 게임 메시지 파일 형식 분석
- 일본어 텍스트 추출 및 한국어 번역 데이터 관리
- 원본 파일을 보존하는 비파괴적 패치 적용
- 적용 전 백업 및 복구 지원
- 패치 결과 자동 검증

## 원칙

- 게임 원본 파일, 실행 파일, 음원, 이미지 등 저작권 데이터는 저장소에 포함하지 않습니다.
- 사용자가 자신의 PC에 설치한 게임 파일을 직접 지정해야 합니다.
- 모든 변경 작업은 백업을 우선하며, 원본 파일 직접 덮어쓰기를 피합니다.
- 포맷이 확인되지 않은 파일을 추측으로 수정하지 않습니다.

## 분석 대상

- `MSG/MESSAGE.N6P`
- `n6data/MESSAGE.N6P`
- `n6data/TABLE.N6P`
- 관련 메시지 데이터 파일

## 진행 단계

1. 파일 구조 및 포맷 식별
2. 읽기 전용 분석기 작성
3. 추출기·재패커 작성
4. 샘플 데이터 round-trip 테스트
5. 한국어 번역 데이터 적용
6. 백업·복구를 포함한 패치 도구 제작
7. 독립 코드 검증 및 실제 게임 테스트

현재는 분석 단계입니다. 포맷이 확정되기 전까지 게임 파일을 수정하지 마십시오.
